# 第 3 轮　限定一次的证据审查

复用问答 Agent 得到的三个冻结快照。在原版 12 块、8,000 token 对照之外，每题用同一专用模型单独审查一次。输入只含用户问题和允许报告内的候选摘录、页码及稳定编号。长候选有界展示。返回已覆盖事实、具体缺项、编号与逐字引文。程序验范围、编号、重复、结构和引文后从原块装入；审查文字不进入最终回答。缺项不触发检索。超时或不合格时恢复原版排序。编号与引文可核验，审查所写事实的蕴含关系未另请人工标注。
