# 按具体事实筛选，并检查最终送达

本轮起点为 `276a658abef5c57be8c3f0095fce51beae0c8546`，实验分支为 `experiment/finance-evidence-selection`。服务器使用新的独立代码目录，不修改其他工作区。原始财报、模型请求、答案、裁判原文及回读原块均保留在私有运行目录。

## 要解决的问题

旧筛选检查引文是否存在，却没有要求逐项说明它能补哪项事实。例如问题缺 2021 年合并收入，只找到 2022 年收入或部门收入不能认定已补齐。旧流程也可能选四块，但长度裁剪后只完整收到其中两块。

新筛选要求返回具体事实、原文行号、对应反馈缺项，以及原文中的指标、期间、口径和单位。原文未明确的信息记为未知。程序检查编号、行号、逐字片段与允许报告范围，再回读原生索引块比对身份和正文指纹。单条无效事实独立记录；如果某个所选块没有有效事实或反馈缺项未逐一交代，本题回退原选择。

表格处理复用 `financial_agent.evidence_lines` 和 `formula_guard.check`。将表头、单位、目标行及附注一同保留；复杂合并单元格保留原文，无法确认时不冒充通过。程序不把模型输出的事实说明放进回答证据，只装原文行。最终在完整请求中逐行检查支持事实的上下文。语义上的支持关系由筛选模型判断，程序只能验证可定位和送达，最终正确性仍由独立裁判检查。

## 对照设计

三个方案共享同一题已经执行过的首搜、主 Agent 缺项、旧池复查和一次补搜，固定模型、回答提示、最多四块及项目原生 8,000 token 长度口径。

1. `fixed`：原版补搜后的四块，必须复现旧请求正文与引用映射。
2. `fact_select`：替换最后一次筛选提示，仍用原装入方式。
3. `fact_deliver`：使用第二组完全相同的块和顺序，整理原文上下文并先扣除问题、指令等固定开销；核对完整实收。无法在预算内装全所列事实则回退本题第一组，记录原因。

只有旧流程确实补搜并增加候选的题才替换最终筛选。未触发题保持原请求。此次不加搜索，不声称解决候选中不存在的证据。所选块数固定为四，是为了隔离改动；不代表生产中四块永远最优。

已冻结全部开发题的候选后，先执行原先固定的三道调优题真实配对，再执行完整 39 题重答评分。完全相同的请求与引用映射在同一实验内共享新生成的答案；不同请求均重新回答。联合指标为答案正确且引用支持都为真；未知、澄清及失败均保留在分母。联合指标翻转题另外重答复验。没有使用旧答案搭配新证据。

## 复现入口

以下入口要求专用模型桥、原生服务及私有数据已配置。所有输出使用新的私有目录；失败后使用同一目录按同条件恢复，成功步骤不重复调用。

```bash
python -m timeguard.fact_tune_trial "$TUNE_SOURCE" "$TUNE_POOLS" "$TUNE_FROZEN" "$TUNE_OUT"
python -m timeguard.fact_final_trial "$DEV_SOURCE" "$DEV_FROZEN" "$DEV_OUT"
python -m timeguard.fact_report "$DEV_OUT" "$PUBLIC_REPORT"
```

完整开发实验支持 `--stage decide|render|answer|grade|report`。前三个阶段不读金标；仅评分和结果汇总读取金标。候选以本题允许公司、披露截止日和冻结索引核验。正文回读是索引请求，与模型筛选、回答和裁判分别计数。

## 三道固定调优题

三组分别为原版、只改事实筛选、事实筛选加完整装入。三组均答对 2/3、答错 1/3；正确且引用支持分别为 1/3、1/3、2/3。首次新增为固定资产周转率题 02987，另外两题没有联合指标变化。变化题独立复验时三组均通过，所以首次新增不代表稳定净收益。没有为该题写特例。

本轮执行 3 次筛选、12 次原文回读、首次回答与裁判各 9 次、复验回答与裁判各 3 次。筛选输入 80,980、输出 2,106 token，累计 102.2 秒；没有新增搜索。13 项由筛选模型列出的事实，原版实收 9 项，另外两组均实收 13 项。既有严格操作数校验器未能核验这三题中的全部操作数，不能据此宣称已自动证明数字和单位正确。独立答案裁判另行判断。

[调优脱敏结果](../reports/fact-evidence-tune.json)。缓存续跑前后均保留 9 份首轮回答、9 份评分及各 3 份复验记录，没有重复模型调用。一次单独启动统计时缺少服务环境变量，在发出请求前停止；随后读取项目既有私有配置完成刷新，未改变模型或证据。

## 完整开发集结果

完整 39 题三组都实际回答和评分，未用旧答案搭配新材料。本轮“原版”是补搜后的固定四块对照，不是最早的原生 medium 最多十二块链路。候选与反馈冻结，因此这是最终节点配对，不是重新执行初搜的端到端验证，也不构成新公司的泛化评估。

| 指标 | 本轮原版 | 只改事实筛选 | 事实筛选＋完整装入检查 |
| --- | ---: | ---: | ---: |
| 答对 / 答错 / 未知 | 22 / 16 / 1 | 27 / 12 / 0 | 25 / 14 / 0 |
| 答对且引用支持 | 22/39 | 26/39 | 25/39 |
| 相对原版新增 / 损失 | — | 4 / 0 | 4 / 1 |
| 选中标准题页 / 46 | 22 | 25 | 25 |

| 完整实收块 / 152 | 140 | 140 | 142 |
| 所列事实完整实收 / 84 | 63 | 77 | 78 |

同一候选池覆盖 31/46 个标准题页组合；此轮没有换检索方法，三个方案候选覆盖相同。84 项事实来自新筛选模型对 19 道有效题的输出，不能作为人工标准事实的召回分母。38 题进入回答模型，1 题需要澄清公司，仍计入全部 39 题并实际评分。严格操作数检查在可识别公式的 19 个需求中均未核验通过，三个方案均为 0/19；这表示当前检查器未能给出证明，不能据此断言数值不存在，更不能声称已自动验证全部单位与公式。

只改筛选首次新增的题为 00460、00684、01079、05915。六道涉及联合指标变化的题全部独立重答三组，重复相同输入共享调用，共追加 15 次回答和 15 次裁判。00460、01079、05915 复验仍是原版未通过、事实筛选通过；00684 的原版复验也通过。首次完整装入组的损失 01107 在复验时三组均未通过，不是稳定的相对损失。不得将这六题的复验混入首轮 39 题，拼成新的全量正确率。

对私有答案和裁判依据进行记录复核后，可以区分以下情况。这些是记录分析，未替代模型标签，也没有另做独立人工逐题裁定。

- 00460：新筛选把题目对应季度的门店表送入前面位置；原版材料是其他年度或口径。两次均救回。
- 01079：新筛选加入当年已完成收购的具体明细；原版主要有协议公告或汇总现金流。两次均救回。
- 05915：新排序把收入和期初、期末固定资产所在表放到前面，两次均完成计算并获引用支持。新装入组要求四块的所列事实全部送达，复杂表无法在预算内全部放入便回退到冻结原版，反而丢掉收益。
- 00684：原版已有关键金额，首次裁判对毛利率舍入差异给未知，新版给正确；复验均正确。不能把它当成明确找回新证据的收益。
- 01077、01107：裁判对叙述答案必须覆盖哪些细节的尺度存在变化。即使部分翻转复现，也不能简单归因于找到或保留了新的关键事实。

新装入相对只改筛选新增 1 题、损失 2 题，净少 1 题；更高的块实收数未转化为更高的联合达标数。三个无法完整装入的题为 00407、00685、05915，相关表含合并单元格，现有实现保留原表，未冒险改变列关系。另有 19 题没有有效的新筛选结果而沿用原版，不能把这 19 题称为预算失败。

## 调用、token 与默认选择

本轮真实新增执行 20 次事实筛选，其中 1 次结构校验失败而回退；回读原文 76 次，失败 0，累计 2.27 秒；没有新增搜索。筛选输入 545,320、输出 15,260 token，累计 686.6 秒。历史同一步筛选也是 20 次，输入 608,546、输出 7,392 token、累计 384.7 秒。新筛选总 token 少 55,358，但输出更长、累计耗时更高；历史时延不是同期服务性能对照。

回答、裁判请求失败均为 0。成功返回但结构未通过的筛选单列，不能当作网络失败。两组新增方案与原版相同的请求仅生成一次，因此实际调用小于各组逻辑调用之和。服务连通性检查另有 3 次模型探测；开发集五个阶段和调优集含缓存刷新共 7 次索引元数据一致性检查，它们属于运行准备，不是按题搜索或原文回读。

按首次净增 4 道联合达标题摊销，本轮新增筛选为每题 5 次，原文回读每题 19 次；按复验仍保持优势的 3 题摊销，分别为约 6.7 次和 25.3 次。上述是实验侧成本，不含表中的回答、裁判及调优费用，不能当作线上每救回一道题的端到端成本。

正常路径可以用新筛选替换旧流程同一步，但本轮异常回退使用冻结原版选择。01936 的该选择与旧池选择不同，在线系统不能无成本获得尚未执行的旧筛选结果；三个装入回退题也存在同样的上线边界。因此不宣称在线额外模型调用为零，生产回退策略和成本尚待从头运行验证。

**后续默认实验候选推荐只改事实筛选。新装入方式保留为实验方案，不默认启用；现有线上默认配置不在本轮直接切换。** 下一步应保住已有效送达的必要事实，避免为附加材料触发回退，并单独处理合并单元格表格。须在明确在线回退规则后做端到端复验，再决定生产启用。不能据此宣称解决了从未检索到的证据。
