## 应用验证

真实 3M 父表的 2018 年带脚注星号，2017 年数值旁的美元符号独占一格。第一版严格列校验对同一问题连续三次拒绝计算。修正方式是识别脚注，并只在同一年覆盖的无标题相邻列内接受唯一金额。有两个可能数值时继续拒绝计算。

修正版 Docker 容器在三个独立会话中通过真实 HTTP 检索、选取操作数、回读、校验及计算，均得到 **(32,765 − 31,657) ÷ 31,657 = 3.5%**。三次分别耗时 9.84、9.41、9.31 秒。这是同一业务样例的重复性检查。容器亦验证了缺参追问、幂等重放与历史截止拒答。项目测试通过 127 项，模型桥测试通过 21 项，覆盖错误 JSON、错误结构、上游失败、超时、容量与熔断恢复。应用仍为单用户单进程；本轮未实现或测试真实逐 token SSE。详见[应用请求记录](../reports/agentic-app-http-20261111.json)和[复现说明](组合链路实验与部署.md)。

## 可用的简历表述

- 在 RAGFlow 原生 Agentic 财报问答链路接入按文档及块编号回读、最终提示实收检查和引用映射；在 8 道专项题上关联 73 次模型请求及 token 用量，用 39 题配对消融量化复查预算的质量与调用开销。
- 基于 FastAPI、Docker 和 Decimal 实现可追溯的财报计算服务，绑定原文行、年份列、币种和单位，处理财报脚注及货币符号错列；同一真实 3M 案例在三个独立会话中均复算出 3.5% 的净销售额增幅。
