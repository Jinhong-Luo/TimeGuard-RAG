# 服务器与网页入口

远程目录是 `/home/luojinghong/LLM_Proj/TimeGuard-RAG`。网页和 API 只绑定服务器回环地址，通过 SSH 使用。

在 Windows 的本仓库目录中运行，保持该终端打开：

```powershell
powershell -File scripts/open_web_tunnel.ps1
```

连接后访问 <http://127.0.0.1:18080>，API 地址为 `http://127.0.0.1:19380`。端口已被现有转发占用时直接使用已有入口；也可用 `-WebPort 18081 -ApiPort 19381` 指定其他本机端口。脚本使用默认 SSH 密钥，不包含密码，不更改主机密钥校验。

项目账户是 `timeguard@localhost.local`。随机登录密码与 API key 仅存于服务器的 `deploy/account.runtime.json`，文件权限为 0600，已排除 Git。需要登录网页时在服务器本地查看该文件，不把内容粘贴到聊天、报告或仓库。Codex 登录由服务器的 `luojinghong` 账户独立维护。

## 查看服务

在服务器项目目录执行：

```bash
docker compose -p timeguard_ljh -f deploy/compose.generated.json ps
docker compose -p timeguard_ljh -f deploy/compose.generated.json logs --tail 80 ragflow-cpu
```

`timeguard_ljh` 是本项目专用名称；持久数据保存在 `data/services`，模型缓存位于 `data/model-cache`。网页启动、PDF 解析完成、模型可用和正式评测完成是四个不同状态，分别以服务状态、解析报告、模型传递证据和评测结果为准。
