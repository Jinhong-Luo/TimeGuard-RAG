## 2026-11-04：部署与评测边界补充

| 问题或现象 | 处理 | 真实状态与限制 |
|---|---|---|
| 原生 TEI 镜像压缩后超过4GB，服务器初始余量约51GB | 使用同系列官方 TEI CPU 1.8 镜像，固定清单及配置摘要 | 约239MB压缩；CPU服务已Ready，固定BGE英文模型已加载 |
| Docker Hub注册入口与代理下载慢；多路SCP又与Retail实验争用链路 | 暂停SCP大文件；只从官方registry取得签名重定向，再从服务器直连官方CDN分段下载 | 每段有超时和重试上限；每层SHA256校验，固定39层内容不变；不更改系统代理 |
| 固定版本官方配置列出华为和阿里镜像，但实际不可用 | 核查匿名鉴权后的tag和不可变manifest路径 | 两个官方国内源均返回404；保留核查报告，未换旧版本或nightly |
| 大文件传输影响同一后端的模型耗时 | 记录约19:17—19:36的SCP竞争窗口并停止传输 | 该窗口实验的耗时不能与无竞争条件直接比较；由总实验报告决定是否重测 |
| Windows与Linux文本换行不同造成查询文件摘要不一致 | 统一生成JSON/JSONL使用LF，原始下载文件不改写 | 服务器150题清单与固定84份PDF已完整落盘；报告见data_preparation.json |
| 选优可能误接受单档或小样本 | 保存完整集合身份，并要求覆盖全部候选档位和完整39题开发集 | 小样本、缺档、重复档、索引变化和未完整人工复核均拒绝选优 |
| 模型裁判可能被误报为人工正确率 | 模型与人工分开计数，模型准确率单独命名，抽查状态保留空值 | 裁判接入已完成离线测试，尚无模型裁判实测结果；不把自动评分伪称人工审核 |
