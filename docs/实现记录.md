## 2026-11-04：原生 GPU 解析准备与长文验证

主镜像已经逐层核验并导入，网页和原生 API 可用。固定版本派生镜像仅补装官方 `torch 2.8.0+cu128` 及其精确依赖，不改 RAGFlow 源码、OCR 模型或系统驱动；基础镜像层前缀、派生配置摘要、原生 ONNX CUDA 会话和真实推理输出均已检查，证据见 `deploy/gpu-image-lock.json`。16 个依赖轮子共 3,907,533,353 字节，服务器从官方源直接下载并逐个校验，实际用时约382秒；没有通过 SSH 再传大归档。

仅使用空闲的物理 GPU 3（RTX 3090），按 UUID 约束。相同 9 页 AMCOR 文档，原 CPU 4核/8GiB条件下原生任务245.58秒，GPU 16核/24GiB条件下54.28秒，均生成18个有效块。CPU和设备同时变化，这只是单文档工程诊断，不能外推全库提速倍率或评测质量。详细原生进度见 `reports/parse_smoke_comparison.json`。
